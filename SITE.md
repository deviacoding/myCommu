# Adresse du site myCommu

**Site en ligne (Firebase Hosting) :** https://mycommunity-b13de.web.app

Adresse équivalente : https://mycommunity-b13de.firebaseapp.com

- Console Firebase du projet : https://console.firebase.google.com/project/mycommunity-b13de/overview
- Dépôt GitHub : https://github.com/deviacoding/myCommu
- Lien à mettre dans un QR code pour rejoindre une communauté : `https://mycommunity-b13de.web.app/rejoindre/XX-0000` (remplacer `XX-0000` par le code de la communauté)

Si l'ancienne version s'affiche après une mise à jour, recharger sans le cache : **Ctrl + Shift + R**.

Pour republier le site après une modification : voir `docs/FIREBASE.md`, section « Déploiement ».
